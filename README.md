# Album Kesayanganku - Shafira 💖

Sebuah album digital interaktif dengan efek 3D dan animasi sinematik, dibuat khusus untuk mengabadikan momen-momen indah bersama Shafira.

## ✨ Fitur Utama
- **3D Hanging Gallery:** Foto-foto yang seolah digantung secara fisik dan berayun alami.
- **Cinematic Transitions:** Transisi foto yang mewah dengan efek shuffle dan depth-of-field.
- **Interactive Parallax:** Elemen latar belakang yang merespon gerakan mouse dan orientasi perangkat.
- **Premium Audio Sync:** Musik latar yang sinkron dengan perpindahan foto secara otomatis.
- **Responsive Design:** Tampilan elegan yang optimal di HP (Mobile) maupun Desktop.

## 🛠️ Tech Stack
- **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Hosting:** [Vercel](https://vercel.com/)

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repository ini.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
