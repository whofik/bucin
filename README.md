# Pink Album Website

Cinematic audio-visual journey built with React, Tailwind, and Framer Motion.

## How to use
1. Put your 5 photos in `public/assets/` named:
   - `p1.jpg`
   - `p2.jpg`
   - `p3.jpg`
   - `p4.jpg`
   - `p5.jpg`
2. Put your music file in `public/assets/` named `music.mp3`.
3. Run `npm install` and `npm run dev`.
4. To deploy to Vercel, simply push this repository or use the Vercel CLI.

## Tech Stack
- Vite + React
- Tailwind CSS (Custom Pink Theme)
- Framer Motion (Animations)
- Lucide React (Icons)
